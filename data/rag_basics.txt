Retrieval-Augmented Generation, or RAG, is a technique where a language model answers a question using information fetched from an external knowledge source instead of relying only on what it memorized during training. The system first searches a collection of documents for passages related to the question, then gives those passages to the model as context. This makes answers more accurate and lets the model use private or recent information it was never trained on.

RAG also reduces hallucination. Because the model is told to answer only from the retrieved passages, it is less likely to invent facts. If the passages do not contain the answer, a well designed system tells the user it does not know. Another benefit is traceability: since each answer is based on specific passages, you can show the user exactly which source was used.
